# Changelog

## 0.2.0 - 2026-06-16

- Added the SVD Studio workbench with light and dark themes.
- Added CMSIS-SVD parsing, round-trip writing, semantic validation and CLI commands.
- Added register map, bit layout, grouped property editing and IDE-style navigation.
- Added device creation, undo/redo, field/enumeration editing, diff and YAML overlays.
- Added tabular import preview for CSV, TSV and XLSX.
- Added icon resources and a PyInstaller release build.
