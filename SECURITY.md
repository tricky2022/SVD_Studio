# Security Policy

## Supported versions

| Version | Supported |
| --- | --- |
| 0.2.x | Yes |
| < 0.2 | No |

## Reporting a vulnerability

Please do not publish exploitable details in a public issue. Contact the project maintainers privately with a description, reproduction steps and affected version. SVD files can contain proprietary device information; remove confidential vendor data before attaching samples.
